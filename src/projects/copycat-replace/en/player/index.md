# Install and use

## Requirements

- **Minecraft 1.20.1 (Forge)** needs Forge **47.4.0+** and Create **6.0.8**.
- **Minecraft 1.20.1 (Fabric)** needs Fabric Loader **0.17.2+**, Fabric API **0.92.6+1.20.1** or later for 1.20.1, and Create Fabric **6.0.8.1 (build 1744)**.
- **Minecraft 1.21.1 (NeoForge)** needs NeoForge **21.1.236+** and Create **6.0.10**.
- Create: Copycats+ is optional. Use **3.0.10** on Fabric and **3.0.4** on Forge or NeoForge.
- Install matching Copycat Replace versions on both client and server, including everyone joining a multiplayer world. Install Copycats+ on both sides to use its shapes.

## First replacement

1. Put the matching addon JAR and required mods in your instance's mods folder.
2. Start the game and enter a world with a Copycat.
3. Hold a **Create Wrench** in one hand and the desired block material in the other.
4. Right-click the Copycat or its selected part. The new material replaces the previous one directly.

Either hand order works. In Survival, the action consumes the required new material and returns the old paid material; a full inventory can cause the refund to drop into the world. Multi-part blocks preserve material shared by their other parts. Creative does not consume material. An invalid material shows a short message above the hotbar, leaves the Copycat intact and consumes the interaction so the Wrench does not rotate or dismantle it.

Hold **Sneak** to use Create's normal Wrench behavior instead.

Read [Connected materials](connected-materials) for group actions and [Configuration](configuration) for limits and file locations.
