# Configuration

Create: On Demand does not add editable configuration files. Its player-facing option is the order mode on each Factory Gauge's recipe screen:

| Mode | Effect |
| --- | --- |
| **Maintain stock and accept orders** | Keeps normal stock replenishment and publishes the gauge's recipe for orders. This is the default for new gauges. |
| **Maintain stock** | Keeps normal stock replenishment and does not accept orders for this gauge. |

The stock slider works in both modes. See [Install and use](./) for the full factory setup and ordering flow.
