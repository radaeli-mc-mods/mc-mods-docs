# Instalação e uso

## Requisitos

Use um loader compatível com sua versão do Minecraft. Instalações Fabric também exigem as versões indicadas do Fabric Loader e da Fabric API.

| Minecraft | Loaders | Requisitos do Fabric |
| --- | --- | --- |
| 1.20.1 | Forge, Fabric | Fabric Loader 0.17.2; Fabric API 0.92.6+1.20.1 |
| 1.21.1 | NeoForge, Fabric | Fabric Loader 0.17.2; Fabric API 0.116.17+1.21.1 |
| 26.1.2 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.155.3+26.1.2 |
| 26.2 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.161.0+26.2 |
| 26.3 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.162.0+26.3 |

## Instalação

1. Escolha o arquivo do Vertical Trapdoors que corresponde à sua versão do Minecraft e ao seu loader.
2. Coloque o arquivo na pasta `mods`. No modo multijogador, instale o mod no cliente e no servidor. No Fabric, instale também a Fabric API nos dois.

## Colocar um alçapão na vertical

1. Mire na lateral de um bloco.
2. Segure **Shift** para colocar o alçapão de modo que ele abra da esquerda para a direita, ou **Alt** para que abra da direita para a esquerda.

Para montar dois alçapões que abrem em direções opostas, coloque-os lado a lado junto a uma parede usando uma tecla diferente para cada um. A colocação funciona normalmente quando você não segura nenhuma das duas teclas ou clica na parte de cima ou de baixo do bloco.

Consulte [Configurações](configuration) para detalhes sobre os controles de colocação.
