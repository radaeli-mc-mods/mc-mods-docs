# Vertical Trapdoors

[![CurseForge](https://cf.way2muchnoise.eu/title/1787624.svg)](https://www.curseforge.com/minecraft/mc-mods/vertical-trapdoors)

Coloque alçapões na vertical junto a paredes e escolha para que lado eles abrem. Você também pode usar alçapões adicionados por outros mods.
