# Install and use

## Requirements

Use a matching loader for your Minecraft version. Fabric installations also require the listed Fabric Loader and Fabric API versions.

| Minecraft | Loaders | Fabric requirements |
| --- | --- | --- |
| 1.20.1 | Forge, Fabric | Fabric Loader 0.17.2; Fabric API 0.92.6+1.20.1 |
| 1.21.1 | NeoForge, Fabric | Fabric Loader 0.17.2; Fabric API 0.116.17+1.21.1 |
| 26.1.2 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.155.3+26.1.2 |
| 26.2 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.161.0+26.2 |
| 26.3 | NeoForge, Fabric | Fabric Loader 0.20.1; Fabric API 0.162.0+26.3 |

## Install

1. Choose the Vertical Trapdoors file that matches your Minecraft version and loader.
2. Put it in the `mods` folder. For multiplayer, install it on both the client and server. On Fabric, install Fabric API on both as well.

## Place a trapdoor upright

1. Aim at the side of a block.
2. Hold **Shift** to place the trapdoor so it opens from left to right, or **Alt** so it opens from right to left.

For example, place two trapdoors side by side against a wall and use a different key for each to give them opposite opening directions. Placement works as usual when you use neither key or click the top or bottom of a block.

See [Configuration](configuration) for details on placement controls.
