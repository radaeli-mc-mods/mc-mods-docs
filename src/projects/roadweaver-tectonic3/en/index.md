# RoadWeaver

[![CurseForge](https://cf.way2muchnoise.eu/title/1358489.svg)](https://www.curseforge.com/minecraft/mc-mods/roadweaver)

The badge opens the upstream project. This documentation covers the [RoadWeaver-Tectonic3](https://github.com/radaelilucca/RoadWeaver-Tectonic3).

> **Disclaimer:** This fork adds support for Tectonic v3 only. No other improvements over the original RoadWeaver have been implemented.

The original **RoadWeaver** is by **shiroha**. All credit for the original mod belongs to its creator: [CurseForge mod page](https://www.curseforge.com/minecraft/mc-mods/roadweaver), [creator's profile and projects](https://www.curseforge.com/members/shiroha/projects), [original GitHub repository](https://github.com/shiroha-233/RoadWeaver).

**Documented version:** 2.4.1-1.21.1 · Minecraft 1.21.1 · NeoForge.

Automatic roads between structures, with support for Tectonic 3.0.28 terrain.
